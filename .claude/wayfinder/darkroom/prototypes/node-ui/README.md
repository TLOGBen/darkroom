# node-ui 草圖：相片編輯節點要內嵌還是開全螢幕

`index.html` 是單一自含檔（沒有外部資源），直接用瀏覽器開即可。上方按鈕切換 A／B 兩版，兩版用的是同一套編輯器元件，只是放的位置不同。

- A 版：節點內嵌——ComfyUI 畫布上一個約 1100×800 的節點，整套 preset 庫／預覽／滑桿／動作列都在節點裡。
- B 版：節點只放縮圖＋摘要（preset、強度、微調幾項、是否有略過）＋「開啟編輯器…」「套用並繼續」「不暫停模式」；點了開全螢幕編輯器（左 preset 庫、中預覽、右滑桿，動作列在上方）。

截圖：`screenshot-A.png`（A 版，已微調 2 項＋分割比較）、`screenshot-B-node.png`（B 版畫布上的節點）、`screenshot-B-editor.png`（B 版全螢幕，開了 AI 補強與 AI 挑 preset）。

## 草圖裡先做的決定

1. **preset 庫**：資料夾樹照 `crs:Group` 分層（器材 → 膠捲 → 富士 這種三層也支援），最上面固定兩個特殊資料夾「★ 最愛」「我的 preset」。搜尋時改成平面結果清單，每筆後面顯示所在路徑。每個 preset 右邊有 ☆ 可直接加最愛。改名／搬移／建資料夾／匯入先做成按鈕（搬移暫時用輸入名稱，正式版想改拖放）。
2. **點 preset 就換掉一切**：強度回 100%、微調清空。這是刻意的——避免舊微調疊到新 preset 上。
3. **滑桿值＝preset 值 × 強度＋微調**。被微調過的滑桿：標籤變橘色加 ●、數值變橘、右邊出現 ↺（只還原這一項）；雙擊滑桿也能還原；群組標題顯示「● 微調 N 項」；動作列有「還原全部微調」。滑鼠停在滑桿上可看到算式。
4. **強度滑桿放在預覽正下方**（不在右邊滑桿欄），因為它是「點 preset → 調強度」主流程的第二步，離預覽近。
5. **預覽**：「按住看原圖」（也可按住 `\` 鍵，同 Lightroom）、「前／後切換」、「分割比較」（可拖分隔線）。右上角顯示「後端算圖中…／已更新」，提醒預覽是後端算的、會有一點延遲。
6. **略過的部分**：引用 Adobe 內建 Look 或含遮罩的 preset，樹上加 ⚠，選了之後預覽上方出現黃色橫條說明哪部分被略過、其餘照套。
7. **AI 補強**放在右欄最下面、預設收起（勾了才展開）；執行結果是**以微調的形式疊上去**，所以一樣看得出、也能逐項還原。「AI 自動挑 preset」放在強度下方，顯示前 3 名縮圖，點了直接套用。
8. **曲線／HSL／顏色分級**：HSL 用「色相／飽和度／明度」三個分頁各 8 條（同 Lightroom 預設排法）；點曲線用 RGB／R／G／B 分頁；顏色分級三個色輪只做顯示，數值用滑桿調。
9. **節點狀態**：標題列右邊有狀態標籤（「等待編輯中（workflow 暫停）」／「已套用，workflow 繼續」／「不暫停：直接用存好的參數」）。節點多一個 `params` 輸入與 `PARAMS` 輸出，方便批次時把參數接進來或存出去。

草圖限制：滑桿只用 CSS 濾鏡粗略模擬（曝光→亮度、對比→對比、飽和／鮮豔→飽和、色溫色調→疊色、暗角、顆粒），曲線／HSL／分級／細節／校正大多不影響圖；B 版節點縮圖沒疊色溫。preset 是 81 個假資料。

## 想請你回答的問題

1. **A 還是 B？** A 版不用切畫面、邊看 workflow 邊調，但節點很大、預覽小、畫布縮小時字會糊；B 版預覽大、畫布乾淨，但要多點一下。還是要「兩者都要」：節點平常是 B 的小樣子，可以展開成 A？
2. **點新 preset 時，強度與微調要不要保留？** 草圖是全部清空。你比較常「換 preset 但保留自己調的曝光」，還是每次重來？
3. **強度滑桿的位置**：放預覽正下方（草圖）可以嗎？還是希望它在右欄最上面、跟其他滑桿放一起？
4. **B 版的全螢幕編輯器裡要不要也有「上一張／下一張」**（批次多張圖時逐張調），還是一次只處理一張就好？
5. **右欄滑桿群組**預設只展開「基本」，其他收起；你平常最常動的是哪幾組？要不要記住上次展開的狀態？
