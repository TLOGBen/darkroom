# ① 節點介面長怎樣？

Type: prototype
Status: resolved

## Question

做一份粗略的介面草圖（HTML 原型即可）給使用者看：preset 資料夾樹（150 群組、兩層）與搜尋、預覽區（前後比較）、強度 %、滑桿分組（基本／曲線／HSL／顏色分級／細節／效果／校正）、AI 補強區、「套用／不暫停」按鈕；放在 ComfyUI 節點裡還是開一個大面板。要決定的是配置與操作方式，不是視覺細節。

## Answer

**使用者決定（2026-10-04，看過 [prototypes/node-ui/index.html](../prototypes/node-ui/index.html) 的 A／B 兩版草圖後）：**
1. **B 版為主、可以展開成 A**：畫布上平常是小節點（縮圖、目前 preset、強度、微調幾項、略過提示、「開啟編輯器」「套用並繼續」「不暫停模式」），點開是全螢幕三欄編輯器（左 preset 庫、中預覽、右滑桿，像 Lightroom 修改模組）；需要時可以把同一套編輯器展開嵌在節點裡（A 版）。
2. **強度 0～200%，點新 preset 時強度回到 100%**；微調使用者沒特別指定，沿用草圖的「點新 preset 時清空微調」。
3. **強度滑桿放預覽正下方**（照草圖）。
4. **全螢幕編輯器要有「上一張／下一張」**，方便批次逐張調。
5. **不用記住滑桿群組的展開狀態**。
6. **保留 `params` 輸入／輸出**（草圖代理的提案：把調好的參數傳給下游節點，或從上游帶進來；使用者回答「流」，主 session 解讀為「留」）。

草圖裡已呈現、使用者沒有反對的其他細節（實作時照做）：微調過的滑桿標橘色＋●、單項 ↺ 還原與雙擊還原、群組標「微調 N 項」、「還原全部微調」；預覽按住看原圖（`\` 鍵）、前後切換、分割比較；含 Adobe Look 或遮罩的 preset 在樹上標 ⚠、選了顯示黃色說明條；AI 補強與「AI 自動挑 preset」（3 張候選）的位置；preset 樹最上方固定「★ 最愛」「我的 preset」。


## Comments

（2026-10-04）載體改為獨立 App（見「① 載體…」）：草圖的 B 版全螢幕三欄編輯器＝App 主畫面；「上一張／下一張」、強度、微調標示、params 等決定都沿用；B 版小節點與 A 版內嵌只在之後做 ComfyUI 節點時才用。
