# ① 「像 Lightroom」的驗收方式？

Type: grilling
Status: resolved

## Question

沒有 Lightroom 可對照。要定：像到什麼程度算過關（觀感相近的標準）、拿什麼來比（賣家附的前後對比圖？使用者以前用 Lightroom 修過的原圖＋成品？）、要不要用視覺 LLM 依 preset 意圖逐項打勾當輔助。答案決定調校方法。


（2026-10-04：研究「① 未公開演算法各用哪個公開方法近似？」指出所有對應數值都只是初值，霧面感的關鍵（Blacks 正值抬多少、Highlights -85 壓多少）沒有參考就無法校正；可選的校正來源多一個：使用者是否願意用 Lightroom 試用期一次渲染「單一滑桿掃描」校正集。）

## Answer

**使用者決定（2026-10-04）：用 Lightroom 免費試用期，一次性渲染「單一滑桿掃描」校正集**（選項 A；另兩個選項是賣家前後對比圖反推、只靠眼睛調）。用完即取消試用。校正集的內容與操作步驟另開「① 校正集要渲染哪些圖、怎麼做？」由代理寫成清單，使用者照做；校正時以校正集的誤差（例如 ΔE、亮度曲線差）為準，眼睛判斷為輔。
