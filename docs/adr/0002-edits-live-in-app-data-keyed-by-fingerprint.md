# 編輯存在 App 資料區，用照片指紋對應，不寫進照片資料夾

Lightroom 的習慣是在照片旁放 sidecar（.xmp），但 darkroom 的照片資料夾常是手機同步或雲端資料夾，多出檔案會被同步、也違反「不碰使用者照片所在處」的原則。所以每張照片的編輯存在 App 資料區（預設 `%LOCALAPPDATA%/darkroom/`，可設定），以照片原檔內容算出的指紋對應：搬移、改名照片不會失去編輯；內容相同的兩個檔案共用一份編輯；照片被其他程式改過就視為新照片（主 session 2026-10-09 代使用者決定）。

## Considered Options

- 照片旁 sidecar：可攜，但會寫進照片資料夾。
- 以路徑對應：簡單，但搬移或改名就失去編輯。
